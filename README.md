## Publish with GitHub Pages
1. Extract the ZIP file.
2. Open your GitHub repository and upload `index.html`, `style.css`, and `README.md` to the repository root.
3. Commit the files to the `main` branch.
4. In the repository, open **Settings → Pages**.
5. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Your public page URL will be shown in the Pages settings.
